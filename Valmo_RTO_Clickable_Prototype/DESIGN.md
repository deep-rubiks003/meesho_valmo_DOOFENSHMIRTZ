# Prototype interface direction

## Surface mode

Operate: a case reviewer should be able to follow a parcel, understand the reason for each decision, and inspect the arithmetic.

## Visual direction

An editorial operations ledger derived from the existing case deck: warm ivory workspace, deep plum navigation and section anchors, orange exception/action states, and restrained green for a confirmed recovery. Dense tables and diagrams should feel like a working dispatch console, not a generic KPI dashboard.

## Interaction rules

- Left navigation switches between workflow stages without losing the selected parcel or editable assumptions.
- Every control names the action and updates a visible parcel state, decision result, or calculation.
- Exceptions remain inline; avoid modal interruption for ordinary workflow.
- Decision rules are readable and editable. Synthetic records and scenario-only calculations are labelled in the interface.
- At narrow widths, navigation collapses and panels stack in task order.

## Type and components

- Use a legible system sans for operational text and tabular figures.
- Use tabular numerals for calculations.
- Use semantic status labels with color; never communicate status by color alone.
- Use one consistent inline SVG line-icon set and clear focus/hover states.
